# Reestar-restaurant-website
A simple and responsive restaurant website built using HTML and CSS. It showcases popular food items with an attractive layout.

## Features

- Responsive design
- Food menu showcase
- Contact section
- Clean and modern layout
- Beginner-friendly project

## Technologies Used

- HTML5
- CSS3
